# cortex-control

The control layer as an MCP plugin: `cortex.commit_decision` (durable domain
memories), `cortex.validate_touchpoints`, `cortex.search_decisions`,
`cortex.list_plugins`; the naming/structure law as resources; the strict
processes (`planning-workflow`, `boundary-guard-checklist`, `build-spec`) as
prompts.

Connect: pick your tool's snippet in `connect/`. Verify: the `cortex.*` tools
appear; ask for the `planning-workflow` prompt and it renders the forced
process. No secrets required.
